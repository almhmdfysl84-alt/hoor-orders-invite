# نسخة الويب — إدارة النقل والطلبات

- ملف الواجهة: `index.html`
- عربية RTL ومتجاوبة مع الهاتف والكمبيوتر، ويمكن فتحها من Safari على iPhone.
- تستخدم مشروع Supabase الحالي نفسه (المفتاح المنشور للعميل فقط، ولا يحتوي الملف على service-role key).
- تتضمن تسجيل الدخول، إنشاء حساب مدير، الطلبات، المصاريف، تغيير الحالة للمدير، وإنشاء حسابات السائقين من Edge Function.

## قبل نشرها للعامة
1. اختبر التسجيل وتأكيد البريد وتسجيل الدخول على مشروع Supabase الحقيقي.
2. تحقق من وجود Edge Function `create-driver` وكونها منشورة، وأنها تفرض تحقق المدير.
3. اختبر سياسات RLS بعائلتي حسابات مختلفتين، للتأكد من عدم قراءة أو تعديل شركة لبيانات شركة أخرى.
4. أضف نطاق الاستضافة إلى Supabase Authentication → URL Configuration → Redirect URLs/Site URL حسب عنوان الاستضافة.
5. انشر هذا المجلد كـ Static Site منفصل. لا تستبدل موقع الدعوات الحالي `invite-site`.

ملاحظة: هذه نسخة أولية تحتاج اختبارًا حيًا على قاعدة البيانات قبل توزيع الرابط على الشركات. لا تحتوي على ملفات APK أو أي بيانات محلية من الجهاز.
